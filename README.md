# 📌 Overview

This project is a fully responsive **YouTube Clone** developed using **ReactJS** and integrated with the **YouTube Data API**.

The application allows users to:

- ▶️ Watch YouTube videos
- 🔍 Search videos dynamically
- 📃 Browse trending and category-based content
- 📱 Enjoy responsive UI across devices
- ⚡ Experience fast rendering with React components

---

# ✨ Features

## 🎥 Video Streaming
- Play YouTube videos directly inside the application
- Embedded YouTube player integration

## 🔎 Smart Search
- Search videos using YouTube API
- Dynamic search results rendering

## 📂 Category Filtering
- Browse videos category-wise
- Interactive sidebar navigation

## 📱 Responsive Design
- Mobile-friendly UI

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/youtube-clone.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd youtube-clone
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start Development Server

```bash
npm start
```

The application will run at:

```bash
http://localhost:3000
```

---

# 🔑 YouTube API Setup

1. Go to Google Developer Console  
2. Enable **YouTube Data API v3**
3. Generate API Key
4. Create `.env` file in root directory

```env
REACT_APP_YOUTUBE_API_KEY=YOUR_API_KEY
```
